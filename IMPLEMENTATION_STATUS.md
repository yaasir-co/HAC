## Architectural choices

The empty repository required a new application rather than an in-place upgrade. Reusable React components and CSS supply the responsive UI; Tailwind/shadcn were not introduced solely to recreate the absent project. The ML implementation uses TensorFlow transfer features plus an index, an explicitly supported hybrid architecture, instead of claiming a trained neural head or a giant classifier. The exact official MobileNet Layers artifact and shared preprocessing were validated rather than relying on the initially invalid TensorFlow Hub URL. Native Prisma tools later verified the guarded initial SQL migration against actual MySQL.
