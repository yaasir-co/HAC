# Shared implementation contract
Workspace is empty except README. User authorizes new code. App at hac-management-system/web, Next16 App Router, TypeScript, Prisma7 MySQL, adapter-mariadb.
DB imports: `import { db } from '@/lib/db'`. Auth imports: `requireUser(request): Promise<AuthUser>`, `assertCompanyAccess(user, companyId): Promise<void>`, `requireRole(user, roles: string[]): void`, `audit(txOrDb, user, action, entityType, entityId, before?, after?, companyId?): Promise<void>`. AuthUser {id,email,name,role,companyId: string|null}. Roles SUPER_ADMIN,HAC_ADMIN,SUPERVISOR,AUDITOR,COMPANY_ADMIN,COMPANY_STAFF. Errors `ApiError(status,code,message)` from lib/errors.ts, `handleError(error):Response`.
REST JSON {data: value, meta?:{page,pageSize,total}}, errors {error:{code,message}}. UI fetch relative /api/v1; credentials cookie. Write requests same-origin Origin validation. Login POST /api/v1/auth/login {email,password}; GET /api/v1/auth/me; POST /api/v1/auth/logout. DB cookie sessions; no public signup.
Core entities schema to be defined by DB agent and communicated. Required conventions: company legalName,tradingName,isDemo; location companyId,name,address; product name,itemCode,brandId,manufacturerId,supplierId nullable, status,isDemo, variants relation; variant productId,sku,barcode nullable, name,packageSize; inspection reference,companyId,locationId,inspectorId,scheduledAt,startedAt,submittedAt,status,version,checklistVersionId,masterDataVersion,snapshot Json nullable; observation inspectionId,productId nullable,variantId nullable, observedName/Brand/Manufacturer/Barcode/Variant nullable, physicalExpiry nullable, batch nullable,quantity nullable, storageLocation nullable,notes nullable,verification Json,conclusion,clientMutationId UNIQUE, createdById,createdAt; certificate number,holderId (Company),issuer,type,status,issuedAt,effectiveAt,expiresAt,supersedesId nullable; certificateScope certificateId,productId,variantId nullable,facilityId nullable,requiresCompanyRelationship bool; companyItem companyId/productId; license manufacturerId or companyId + name/number/expiresAt; restriction productId nullable,manufacturerId nullable,authority,reference,reason,effectiveAt,expiresAt nullable,status; investigation reference,companyId,inspectionId nullable,productId nullable,observationId nullable,title,description,priority,status,assignedToId,createdById; NC/corrective action/complaint similarly.
UI main APIs: GET /dashboard; GET+POST /companies /products /certificates /inspections /investigations /complaints /non-conformities /corrective-actions /notifications /users /audit-logs /checklists. GET /companies/:id and /products/:id; GET /inspections/:id includes company,location,inspector,observations,findings,investigations,signatures,checklistVersion + responses. POST /inspections/:id/start; POST /inspections/:id/observations (accept observation fields, requires clientMutationId), POST /inspections/:id/checklist {questionId,answer,notes}; POST /inspections/:id/sign {name,role,signature?,reason?}; POST /inspections/:id/submit {version, declaration:true}; POST /inspections/:id/review {decision:'APPROVED'|'CLARIFICATION_REQUIRED',reason}; POST /verification {productId,variantId,companyId,locationId?,observedBrand?,observedManufacturer?,observedBarcode?,observedVariant?,physicalExpiry?,identityConfirmed:boolean}. Root owns domain API and tests integration.
Report agent owns GET /api/v1/reports/:inspectionId?format=pdf|xlsx; evidence POST /api/v1/evidence multipart file,inspectionId,observationId optional; GET /api/v1/evidence/:id. Respect auth and immutable submitted inspections. No public deploy or production access.
AI agent owns src/lib/ai/**, src/components/ai/**, src/app/api/v1/ai/** and AI tests. UI imports TrainingStudio and Scanner from components/ai (default exports named files). Scanner props `{inspectionId?:string,onSelect:(productId:string,variantId?:string)=>void}`. TrainingStudio no props. AI stored in schema `TrainingDataset`, `TrainingImage`, `ModelVersion`, `RecognitionPrediction`; communicate needs DB agent. Real TFJS MobileNet embeddings + versioned index acceptable. No simulated scores or accuracy.
